Fonte dos dados do Maps

Chave do Serper.dev

  1. Crie sua conta em serper.dev (dá para entrar com o Google).
  2. No painel, copie a API key.
  3. Cole aqui e clique em Testar conexão.
  4. Atenção: em alguns negócios (restaurantes, por exemplo) a fonte pode não trazer o site. Confira no Maps antes de abordar.

Chave Google Places API (New)

  1. Entre em console.cloud.google.com e crie um projeto.
  2. Ative o faturamento do projeto (o Google exige para a Places API; confira os limites gratuitos na página de preços).
  3. Em APIs e serviços, Biblioteca, ative a Places API (New).
  4. Em Credenciais, crie uma chave de API, restrinja ao uso da Places API (New) e, se hospedar o arquivo, ao seu domínio.
  5. Cole a chave acima e clique em Testar conexão. Ela fica salva só neste navegador.
